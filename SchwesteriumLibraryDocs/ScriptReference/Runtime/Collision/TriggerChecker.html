TriggerChecker

Triggerが特定のレイヤーのオブジェクトを検知したら、イベントを発火する。

継承 : MonoBehaviour

Colliderが必要。IsTrigger を有効にして使う。
オブジェクトが破棄されるとき、登録されているイベントはすべて解除される。

変数

名前 型 説明
OnEnter event Action<Collider> 指定したレイヤーのオブジェクトがTriggerに入ったときに発火する。引数は入ってきた Collider
OnExit event Action<Collider> 指定したレイヤーのオブジェクトがTriggerから出たときに発火する。引数は出ていった Collider
Collider Collider このオブジェクトの Collider(読み取り専用)
