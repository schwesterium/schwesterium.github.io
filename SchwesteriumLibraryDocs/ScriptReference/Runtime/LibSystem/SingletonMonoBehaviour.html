SingletonMonoBehaviour<T>

MonoBehaviour を継承したシングルトンの基底クラス。

継承 : MonoBehaviour

T には派生クラス自身を指定する。
Awake と OnDestroy は基底クラスが使用しているため、派生クラスでは OnAwake() と OnDestoryed() を override して使う。
すでにインスタンスが存在する場合、後から生成されたインスタンスは Awake 時に GameObject ごと破棄される。

変数

名前 型 説明
Instance static T 唯一のインスタンス。存在しない場合は null(読み取り専用)

Protected関数

定義 関数の説明 戻り値の説明
virtual void OnAwake() Awake時、インスタンスの登録後に呼ばれる void
virtual void OnDestoryed() OnDestroy時に呼ばれる void
