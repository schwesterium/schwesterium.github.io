TextDisplayer<T>

TextMeshProUGUI に値を表示するための抽象クラス。 T型の値を ToString() して表示する。

継承 : MonoBehaviour

TextMeshProUGUI が必要。

変数

名前 型 説明
_text protected TextMeshProUGUI 同じGameObjectの TextMeshProUGUI。Awake時に取得される

Public関数

定義 関数の説明 戻り値の説明
virtual void OnStart() Awake時、_text の取得後に呼ばれる。初期化処理用 void
virtual void SetText(T text) text を ToString() した文字列を表示する
text: 表示する値		 void
