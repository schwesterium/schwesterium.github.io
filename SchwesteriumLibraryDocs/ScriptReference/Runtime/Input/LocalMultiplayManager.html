LocalMultiplayManager

コントローラー接続・プレイヤー参加管理を行う。

実装インタフェース : IDisposable

コンストラクタ

定義 引数
LocalMultiplayManager(int maxPlayers, GameObject[] playerObjs,
bool useKeyboard, bool initResister)		 maxPlayers: 最大人数
playerObjs: IInputHandlerOwnerを実装したクラスを持つGameObjectの配列
useKeyboard: キーボード入力を有効にする
initResister: Init() 実行時、接続済みデバイスを登録する

変数

名前 型 説明
KEYBOARD const string Bindingに使うgroupsの名前
GAMEPAD const string Bindingに使うgroupsの名前

Public関数

定義 関数の説明 戻り値の説明
void Init() 初期化処理 void
void StartRegisterDevice() デバイスの登録を開始する void
void EndRegisterDevice() デバイスの登録を終了する void
void RegisterAllDevices() 接続済みのデバイスをすべて登録する void
void SetActiveUnassignedPlayer() 未割当のプレイヤーオブジェクトを非表示にする void
