PointerPaths

InputSystem用 ポインター(マウス・タッチ・ペンなど)共通のコントロールパス。

定数

名前 型 説明
POSITION const string ポインターの位置
<Pointer>/position
DELTA const string ポインターの移動量
<Pointer>/delta
PRESS const string 押下状態
<Pointer>/press
PRESSURE const string 押下圧
<Pointer>/pressure
RADIUS const string 接触面の半径
<Pointer>/radius
TWIST const string ペンのひねり
<Pointer>/twist
