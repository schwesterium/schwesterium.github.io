GUISize

Editor拡張のGUI描画で使う、共通のサイズ定数を提供するクラス。 Width・Height・Space は定数、Layout は GUILayoutOption を返す。

定数

GUISize.Width

名前 型 説明
S const float 60 : 幅(小)
M const float 100 : 幅(中)
L const float 160 : 幅(大)
Label const float 120 : ラベルの幅
Icon const float 24 : アイコンの幅

GUISize.Height

名前 型 説明
S const float 18 : 高さ(小)
M const float 24 : 高さ(中)
L const float 32 : 高さ(大)
XL const float 48 : 高さ(特大)

GUISize.Space

名前 型 説明
XS const float 2 : 余白(極小)
S const float 4 : 余白(小)
M const float 8 : 余白(中)
L const float 16 : 余白(大)
XL const float 24 : 余白(特大)

変数

GUISize.Layout

名前 型 説明
WidthS static GUILayoutOption GUILayout.Width(Width.S)
WidthM static GUILayoutOption GUILayout.Width(Width.M)
WidthL static GUILayoutOption GUILayout.Width(Width.L)
HeightS static GUILayoutOption GUILayout.Height(Height.S)
HeightM static GUILayoutOption GUILayout.Height(Height.M)
HeightL static GUILayoutOption GUILayout.Height(Height.L)
HeightXL static GUILayoutOption GUILayout.Height(Height.XL)
