2進数

我々が普段使う、0~9までの数字と位取りによって数を表す方法は 「10進数」と呼ぶ。 使う数字が0と1で、同様の位取りを行う数値表現法が 「2進数」である。 2進数は2つの数字で数を表せるため、スイッチのオン・オフや電圧の高低などと対応させることができる。

10進数は1桁目が1の位、2桁目が10の位、3桁目が100の位...のように、n桁目は \(10^{n-1}\) の位となる。 これ同様に、2進数では1桁目が1の位、2桁目が2の位、3桁目が4の位...と、n桁目は \(2^{n-1}\) の位となる。

基数変換

「基数」とは位取り記数法での数値表現の際、各桁の重みとなる数。2進数の場合、基数は2になる。

n進数から10進数への変換

基数を\(n\)、桁数を\(k\)、\(n\)進数の整数部分を下の桁から順に、\(d_0,d_1,d_2 ... d_{k-1}\)とするとき、10進数の値\(N\)は
\(N = d_0 \times n^0 + d_1 \times n^1 + d_2 \times n^2 ... d_{k_1} \times n^{k-1}\)

少数の場合は、指数を逆数に

実際に、2進数 1110 を変換してみよう。

計算手順

基数は2、桁数は4である。1110を上記の式に当てはめると以下の通り
\(0 \times 2^0 + 1 \times 2^1 + 1 \times 2^2\ + 1 \times 2^3\)
計算すると \(0 + 2 + 4 + 8\) となる。
よって、答えは\(14\)

次に、16進数 7F3B を変換してみよう。

「16進数」とは、0~9とA~Fの英数字による数値表現法である。Aが10に、Fが15にあたる。

計算手順

基数は16、桁数は4であるから、式は以下の通り
\(B \times 16^0 + 3 \times 16^1 + F \times 16^2\ + 7 \times 16^3\)
Fは15、Bは11。計算すると \(11 + 48 + 3840 + 28672\) となる。
よって、答えは\(32,571\)

10進数からn進数への変換

10進数の整数を\(n\)進数に変換するには、「商が0になるまで\(n\)で割り続け、余りを逆順に並べる」という方法を使う。 最初に出た余りが最下位桁(1の位)、最後に出た余りが最上位桁になる。

まず、10進数 25 を2進数に変換してみよう。

計算手順

25を2で割り続ける。
\(25 \div 2 = 12\) 余り \(1\)
\(12 \div 2 = 6\) 余り \(0\)
\(6 \div 2 = 3\) 余り \(0\)
\(3 \div 2 = 1\) 余り \(1\)
\(1 \div 2 = 0\) 余り \(1\)
余りを下から順に並べると \(11001\)
検算すると \(1 \times 2^4 + 1 \times 2^3 + 0 + 0 + 1 \times 2^0 = 16 + 8 + 1 = 25\) となり、一致する。
よって、答えは\(11001\)

次に、10進数 32,571 を16進数に変換してみよう。

計算手順

32571を16で割り続ける。
\(32571 \div 16 = 2035\) 余り \(11\)
\(2035 \div 16 = 127\) 余り \(3\)
\(127 \div 16 = 7\) 余り \(15\)
\(7 \div 16 = 0\) 余り \(7\)
余りを下から順に並べると \(7, F, 3, B\)
よって、答えは\(7F3B\)
先ほど変換した値と一致している。

2進数と16進数の相互変換

16は\(2^4\)であるため、16進数の1桁はちょうど2進数の4桁に対応する。 この性質により、10進数を経由せずに直接変換できる。 2進数を下の桁から4桁ずつ区切り、それぞれを16進数の1桁に置き換えればよい。

例 : 2進数 1111 1100 0011 を16進数に変換

\(1111 = F\)、\(1100 = C\)、\(0011 = 3\) であるから、答えは\(FC3\)
逆に16進数から2進数へ戻す場合は、1桁ずつ4桁の2進数に展開すればよい。
