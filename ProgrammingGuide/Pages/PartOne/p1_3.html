条件分岐とは

指定した条件が満たされたどうかで、次に実行するプログラムを変えることである。

偶数の判定について、条件分岐を使用して考えてみる。
整数が2で割り切れる場合は偶数と表示する

if文

与えられた条件文が満たされている場合は、ifに続く{}の内の処理を実行する。

例を実際にコードにしてみよう。

ソースコードを見る (Sec3_1) 

int number = 5;

//numberを2で割った余りが0なら偶数
if (number % 2 == 0) //if(条件文)
{
    //真の場合の処理
    Console.WriteLine("numberは偶数");
}
実行結果 (Sec3_1) 

※numberは奇数であるため、実行しても何も表示されない。

比較演算子

Sec3_1で使われた==のように、左辺と右辺を比較して真偽を調べる演算子を指す。

C#の比較演算子は以下の通り。

演算子 意味 使用例
== 左辺と右辺が等しいか a == b
!= 左辺と右辺が等しくないか a != b
> 左辺が右辺より大きいか a > b
< 左辺が右辺より小さいか a < b
>= 左辺は右辺以上か a >= b
<= 左辺は右辺以下か a <= b

else, else if

ifの条件が成り立たないときの処理はelseを使うことで行える。また、条件が3つ以上に分かれるときはelse ifを使う。

Sec3_1に加えて、elseを使い奇数だった時の表示をしてみよう。

ソースコードを見る (Sec3_2) 

int number = 5;

if (number % 2 == 0)
{
    Console.WriteLine("numberは偶数");
}
else
{
    //偽の場合、今回は奇数の場合
    Console.WriteLine("numberは奇数");
}
実行結果 (Sec3_2) 

numberは奇数

点数に応じて、80点以上なら「優」79~50点を「可」それ以外は「不可」と成績を出すプログラムを書いてみよう。

ソースコードを見る (Sec3_3) 

int score = 75;

if (score >= 80)
{
    Console.WriteLine("優");
}
else if (score >= 50)
{
    Console.WriteLine("可");
}
else
{
    Console.WriteLine("不可");
}
実行結果 (Sec3_3) 

可

条件は上から順に調べられ、最初に成り立ったものだけが実行される。上の例の場合、最初の条件は偽、次の条件が真なので「可」と表示され、残りは調べられない。

条件が3種類以上あるときの書き方

条件が増えるにつれ、if, else if, else if, ... , elseと、else ifの書く量が増えていく。
その場合、「switch文」が使われることもあり、より簡潔に書くことができるようになる。
とはいえケースバイケースであるため、まずはif文を使えるようになり、そのうえで使い方調べるとよい。

条件を組み合わせる

条件式は複数の条件を組み合わせることができ、これを行うには「論理演算子」を使う

演算子 意味 呼び方 使用例
& 左辺かつ右辺が真なら真になる AND、論理積 A & B
| 左辺または右辺が真なら真になる OR、論理和 A | B
^ 左辺または右辺が真のときのみ真になる XOR、排他的論理和 A ^ B
! その条件式の否定を行う。trueならfalse、falseならtrue NOT、論理否定 !(A & B)
&& 短絡評価を行うAND 条件付き論理AND演算子 A && B
|| 短絡評価を行うOR 条件付き論理OR演算子 A || B

「短絡評価」とは

左辺の結果だけで条件式全体の値が確定した時に、右辺の評価を省略する仕組みである。
&&は左辺が偽なら、その時点で条件式が偽であることが確定しているため、右辺は評価されない。
||は左辺が真なら、その時点で条件式が真であることが確定しているため、右辺は評価されない。

18歳以上かつ入場チケットを持っている人が入場できる ("入場できます"と表示する) プログラムを書いてみよう。

ソースコードを見る (Sec3_4) 

int age = 18;
bool hasTicket = true;

if(age >= 18 && hasTicket)
{
    Console.WriteLine("入場できます");
}
実行結果 (Sec3_4) 

入場できます

繰り返しとは

同じ処理を、指定した回数または条件が満たされている間、繰り返し実行することである。

1から5までの整数を順番に表示することを考えてみる。
Console.WriteLineを5回書くこともできるが、10000回なら現実的ではない。
このような場合、繰り返しを使えば、短いコードで同じ処理を何度でも実行できる。

for文

指定した回数だけ同じ処理を行う。構文は以下の通り


for (初期化; 条件文; 更新)
{
    //繰り返したい処理
}
部分 意味 実行されるタイミング
初期化 カウンタ変数の用意 繰り返しの開始時のみ
条件文 繰り返しを続けるかどうかの判定 処理の実行前に毎回
更新 カウンタ変数の値を増減させる 処理の実行後に毎回

1から10までの合計を求めるプログラムを書いてみよう。

ソースコードを見る (Sec3_5) 

int sum = 0;

for (int i = 1; i <= 10; i++)
{
    sum += i;
}

Console.WriteLine("合計: " + sum); //文字列の結合
実行結果 (Sec3_5) 

合計: 55

break, continue

繰り返しの途中で、処理の流れを変えることができる。

キーワード 意味
break 現在のループを即座に終了する
continue 今回のループの残りの処理を飛ばし、次のループへ進む

breakを使い、iが5になったら繰り返しを終了するプログラムを書いてみよう。

ソースコードを見る (Sec3_6) 

for (int i = 0; i < 10; i++)
{
    if (i == 5)
    {
        //iが5になった時点でforを抜ける
        Console.Writeline("ループ終了！");
        break;
    }
    Console.WriteLine(i);
}
実行結果 (Sec3_6) 

0
1
2
3
4
ループ終了！

continueを使い、1から10までの整数のうち奇数だけを表示するプログラムを書いてみよう。

ソースコードを見る (Sec3_8) 

for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        continue; //偶数なら以降の処理を飛ばして次の繰り返しへ
    }
    Console.WriteLine(i);
}
実行結果 (Sec3_8) 

1
3
5
7
9

while文

条件文が真である間、処理を繰り返す構文である。


while (条件文)
{
    //繰り返したい処理
}

1から始めて、2倍にし続けて100以上になるまでの回数を調べるプログラムを書いてみよう。

ソースコードを見る (Sec3_8) 

int number = 1;
int count = 0;

while (number < 100) //100未満の間は処理を続ける
{
    number *= 2;
    count++;
}

Console.WriteLine(count + "回で" + number + "になった");
実行結果 (Sec3_8) 

7回で128になった
