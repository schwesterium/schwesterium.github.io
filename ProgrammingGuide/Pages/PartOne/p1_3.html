条件分岐とは

指定した条件が満たされたどうかで、次に実行するプログラムを変えることである。

偶数の判定について、条件分岐を使用して考えてみる。
整数が2で割り切れる場合は偶数と表示する

if文

与えられた条件文が満たされている場合は、ifに続く{}の内の処理を実行する。

例を実際にコードにしてみよう。

ソースコードを見る (Sec3_1) 

int number = 5;

//numberを2で割った余りが0なら偶数
if (number % 2 == 0) //if(条件文)
{
    //真の場合の処理
    Console.WriteLine("numberは偶数");
}
実行結果 (Sec3_1) 

※numberは奇数であるため、実行しても何も表示されない。

比較演算子

Sec3_1で使われた==のように、左辺と右辺を比較して真偽を調べる演算子を指す。

C#の比較演算子は以下の通り。

演算子 意味 使用例
== 左辺と右辺が等しいか a == b
!= 左辺と右辺が等しいか a != b
> 左辺が右辺より大きいか a > b
< 左辺が右辺より小さいか a < b
>= 左辺は右辺以上か a >= b
<= 左辺は右辺以下か a <= b

else, else if

ifの条件が成り立たないときの処理はelseを使うことで行える。また、条件が3つ以上に分かれるときはelse ifを使う。

Sec3_1に加えて、奇数だった時の表示をしてみよう。

ソースコードを見る (Sec3_2) 

int number = 5;

if (number % 2 == 0)
{
    Console.WriteLine("numberは偶数");
}
else
{
    //偽の場合、今回は奇数の場合
    Console.WriteLine("numberは奇数");
}
実行結果 (Sec3_2) 

numberは奇数
