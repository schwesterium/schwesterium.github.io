Programming Guide

変数とは

データを記憶しておくための領域に名前を付けたもので、必要に応じてデータの出し入れができる。

ゲームでの得点について、変数を使用して考えてみる。
"score"という得点の変数があったとする。当然、ゲームの最初は持っている得点は0であるから、"score"は0が入っている。
ここで、10点得るコインを取ると、"score"は+10され、"score"は10になる。
さらに、コインを3枚取ると、"score"は+30され、"score"は40になる。 ゲームクリア時、"score"を利用してリザルト画面に得点を表示する。

さて、上記の例を実際にコードにして入力しよう。

ソースコードを見る (Code1_1) 

//変数の宣言 データを記憶しておくための領域（箱）に名前をつける
int score;          //得点を保持

//変数に値を代入する
score = 0;          //ゲーム開始時は0点

score = score + 10; //コインを取った！
score = score + 30;

Console.WriteLine(score); //得点を表示する

イコール(=)は、左辺と右辺が等価であることを意味するが、C#やJavaなどにおいては代入として表す。(後述)

実行すると、画面に変数の値が表示される。実行結果は以下の通り。

実行結果 (Code1_1) 

40

変数は、箱として例えられることが多い。
「変数名」が箱の名前、「型名」が箱に入れるものの種類である。 今回書いたコードの場合、scoreが変数名、その左にあるintが型名となる。

型とは

プログラムが扱うデータの種類や記録方法などを定めたもの。「型」以外に「データ型」と呼ぶこともある。

型に様々な種類があり、よく使われるものは以下の通り。

型名 意味 表現できる値 デフォルト値
int 整数 -2,147,483,648 ~ 2,147,483,647 0
float 単精度浮動小数点数 -3.4E^38 ~ +3.4E^38 0.0f
double 倍精度浮動小数点数 -1.7E^308 ~ +1.7E^308 0.0
bool 真偽値 true または false false
string 文字列 文字の羅列 null
char 文字 単一のUnicode文字 '\0'

変数を使う

変数の宣言と代入

Code1_1の2行目、int score;はscoreという名前のint型の変数を作っている。 変数の作成を「変数の宣言」と呼ぶ。
5行目では、score = 0;と書くことで、変数scoreに整数0を入れている。 変数に値を入れることを「代入」と呼ぶ。
また、変数の宣言と共に代入をすることが可能であり、int score = 0;と書くことで、scoreに最初から0を持たせることができる。 このように、変数に初期値を持たせることを「変数の初期化」と呼ぶ。

変数名の規則

変数名のつけ方には規則があり、次の規則に従わない場合はエラーとなる。

  • 変数名の先頭は、文字またはアンダースコア(_)で始めなければならない
  • C#で使う予約語と一致する名前は付けられない
  • Unicodeは含めることができる

Unicodeに含まれる文字を変数名に使うことはできるものの、様々な理由から使われることはない。

C#では予約語のことをキーワードと呼ぶ。

演算

変数や数値を使って計算を行うことを「演算」と呼び、演算に使う記号を「演算子」と呼ぶ。

四則演算に使う演算子（算術演算子）は以下の通り。

演算子 意味 例 結果
+ 加算 10 + 2 12
- 減算 10 - 2 8
* 乗算 10 * 2 20
/ 除算 10 / 2 5
% 剰余（余りを求める） 10 % 2 0

実際に、上記の演算子を使ってみよう。

ソースコードを見る (Code1_2) 

int a = 11;
int b = 3;

Console.WriteLine(a + b);   //加算
Console.WriteLine(a - b);   //減算
Console.WriteLine(a * b);   //乗算
Console.WriteLine(a / b);   //除算
Console.WriteLine(a % b);   //剰余

//計算結果を変数に代入することもできる
int sum = a + b;
Console.WriteLine(sum);
実行結果 (Code1_2) 

14
8
33
3
2
14

実行結果を確認して、「除算の結果が正しくない」と疑問に思った人もいるだろう。
これは、整数同士の除算では、結果は整数となり小数点以下は切り捨てられるからだ。 小数で求めたい場合は、最低でもどちらかを小数の型にしなければならない。

実際に、型による除算結果の違いを確認しよう。

ソースコードを見る (Code1_3) 

Console.WriteLine(7 / 3);        //整数同士
Console.WriteLine(7.0f / 3);     //小数が含まれる
Console.WriteLine(7 / 3.0f);     //どちらか一方でもよい
実行結果 (Code1_3) 

2
2.3333333
2.3333333

除算を行う際、0で割ると実行時にエラー（例外）となりプログラムが停止するため、0で割らないように注意すること。

この、0で割ることを「0除算」と呼ぶ。

演算の優先順位

算数と同じように、*、/、%は+、-よりも先に計算される。 また先に計算したい部分は、( )で囲むことで優先できる。

実際に、演算の優先順位を確認しよう。

ソースコードを見る (Code1_4) 

Console.WriteLine(2 + 3 * 4);    //乗算 -> 加算
Console.WriteLine((2 + 3) * 4);  //括弧内の加算 -> 乗算
実行結果 (Code1_4) 

14
20

複合代入演算

Code1_1では、得点を加算するためにscore = score + 10;と書いた。 このように「変数を使って計算し、その結果を同じ変数に代入する」処理はよく使われるため、簡潔に書くための演算子が用意されている。これを「複合代入演算子」と呼ぶ。

演算子 意味 同じ意味の書き方
+= 加算して代入 a = a + b;
-= 減算して代入 a = a - b;
*= 乗算して代入 a = a * b;
/= 除算して代入 a = a / b;
%= 剰余を代入 a = a % b;

ここで、Code1_1を複合代入演算子で書き換えてみる。

ソースコードを見る (Code1_5) 

int score;

score = 0;          //ゲーム開始時は0点

score += 10;        //コインを取った！ (score = score + 10 と同じ)
score += 30;

Console.WriteLine(score);   //40
実行結果 (Code1_5) 

40

インクリメント・デクリメント

値を1だけ増やす操作を「インクリメント」、1だけ減らす操作を「デクリメント」と呼ぶ。 これらは専用の演算子で簡単に書ける。

演算子 名前
++ インクリメント
-- デクリメント

実際に、上記の演算子を使ってみよう。

ソースコードを見る (Code1_6) 

int count = 5;

count++;                    //6になる
Console.WriteLine(count);

count--;                    //5に戻る
Console.WriteLine(count);
実行結果 (Code1_6) 

6
5

前置と後置による処理の違い

++と--は、変数の前に付ける「前置」（++a）と、後ろに付ける「後置」（a++）の2種類の書き方がある。 単独で使う場合はどちらも結果は同じだが、他の式の中で使う場合は値の扱われ方が異なる。

違いは以下の通り。

  • 前置 : 先に値を1増やし、増えた後の値が式の結果になる
  • 後置 : 先に現在の値が式の結果になり、その後で値が1増える

実際に、前置と後置による処理の違いを確認しよう。

ソースコードを見る (Code1_7) 

int a = 5;
int b = a++;    //bに5が代入され、その後aが6になる
Console.WriteLine(a);
Console.WriteLine(b);

int c = ++a;    //aが7になり、その7がcに代入される
Console.WriteLine(a);
Console.WriteLine(c);
実行結果 (Code1_7) 

6
5
7
7
