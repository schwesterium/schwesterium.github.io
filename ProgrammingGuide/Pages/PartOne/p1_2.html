変数とは

データを記憶しておくための領域に名前を付けたもので、必要に応じてデータの出し入れができる。

ゲームでの得点について、変数を使用して考えてみる。
"score"という得点の変数があったとする。当然、ゲームの最初は持っている得点は0であるから、"score"は0が入っている。
ここで、10点得るコインを取ると、"score"は+10され、"score"は10になる。
さらに、コインを3枚取ると、"score"は+30され、"score"は40になる。 ゲームクリア時、"score"を利用してリザルト画面に得点を表示する。

さて、上記の例を実際にコードにして入力しよう。

ソースコードを見る (Code1_1) 

//変数の宣言 データを記憶しておくための領域（箱）に名前をつける
int score;          //得点を保持

//変数に値を代入する
score = 0;          //ゲーム開始時は0点

score = score + 10; //コインを取った！ 今の得点に、+10した値を得点として保存する
score = score + 30;

Console.WriteLine(score); //得点を表示する

実行すると、画面に変数の値が表示される。実行結果は以下の通り。

実行結果 (Code1_1) 

40

変数は、箱として例えられることが多い。
「変数名」は箱の名前、「型名」は箱に入れるものの種類である。 今回書いたコードの場合、scoreが変数名、その左にあるintが型名となる。

型とは

プログラムが扱うデータの種類や記録方法などを定めたもの。「型」以外に「データ型」と呼ぶこともある。

型に様々な種類があり、よく使われるものは以下の通り。

型名 意味 表現できる値 デフォルト値
int 整数 -2,147,483,648 ~ 2,147,483,647 0
float 単精度浮動小数点数 -3.4E^38 ~ +3.4E^38 0.0f
double 倍精度浮動小数点数 -1.7E^308 ~ +1.7E^38 0.0
bool 真偽値 true または false false
string 文字列 文字の羅列 null
